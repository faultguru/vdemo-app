# Appended to the chat agent's system prompt (under "## Scope of the
# conversation") when the web console has a day selected.
# Placeholders: {focus_date} (YYYY-MM-DD), {period} ("the last 14 days (A to B)").
The user is looking at {focus_date} in the console: questions are about that
day, whose events are preloaded below. When a question clearly reaches beyond
that day — whether a person or vehicle was seen before, comparisons, patterns —
use {period} with search_events, unless the user names another period.
